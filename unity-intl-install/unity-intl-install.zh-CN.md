# 国际版 Unity 安装注意事项

在国内直接使用国内版 Unity Hub 或浏览器下载时, 经常会被自动重定向到国内特供版或团结引擎。建议通过以下方式获取标准国际版:

- **使用 VCC 自动安装(推荐)**: 直接在 VCC 中创建项目或打开设置, 让 VCC 自动调用链接引导安装指定的国际版 Unity(如当前主流的 2022.3.22f1)。
- **手动下载国际版**: 如果开启 Hub 下载被强制切回国区, 需要开启网络代理访问 Unity 官方 Archive 页面下载对应的独立安装包(Download Assistant / 离线包), 确保安装后的版本号没有任何 c 或 c1 等后缀。
